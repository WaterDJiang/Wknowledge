# 表格范围解析与精确回源 M4-03 Spec v1

## 1. 关联计划

- 工作包：`M4-03`，依赖 M2-08 `CompiledNode`、M4-08/M4-09 授权来源预览与不可变 `ResourceVersion`。
- 状态：已验证。本切片将 CSV/XLSX 的内容解析为稳定、可回查的工作表范围；不新增模型、OCR、Embedding、在线编辑或写回原始文件。

## 2. 目标

- CSV 和 XLSX 产生 `sheet` 类型 SourceLocator，不再将表格行列伪装为通用 document 节点。
- 每个已发布表格节点能够精确定位至一个受权的工作表范围，查询、Wiki、学习和题目继续使用同一 `wk://source`。
- 来源页能够展示对应范围的安全文本预览；原 XLSX 仍只提供下载，不在页面中执行 Office 内容。

## 3. 解析与范围规则

```text
CSV  → 工作表“CSV” → 非空连续行块 → A{start}:<lastColumn>{end}
XLSX → 每个工作表 → 空行分隔的非空连续行块 → A1 形式范围
```

- 解析只读取公式字符串和显示值：XLSX 节点正文写入显示值，`metadata.formulas` 仅保留相同范围内非空公式；不求值、不执行宏、外链或公式。
- 对所有节点限制每块最多 200 行、40 列、200 KiB UTF-8 正文；单元格和公式摘要各最多 4,096 字符，单节点最多记录 1,000 条公式。超过时继续分块或显式截断，防止单节点、Wiki 或预览无限膨胀。
- 空表不产出节点；合并单元格、隐藏行/列等仅作为只读元数据，不改变定位范围的语义。
- CSV 的分隔符以 Python `csv.Sniffer` 在安全样本中探测，失败时回退逗号；UTF-8 仍由上传准入保证。

## 4. 来源预览

- 新增受权只读的 sheet-preview API：根据 `wk://source` 读取同一资源版本的已发布 `nodes.json`，只返回所请求 `sheet + range` 匹配节点的文本、公式摘要和元数据。
- API 继续重核登录与空间 `viewer`；不返回 Blob URI、真实路径、整份工作簿或其他范围的节点。
- 来源页面对 sheet 定位渲染文本表格预览与范围标签；当派生文件不可用时提示下载受权原件，不伪造范围内容。

## 5. 验收标准

- 包含空行、公式、多个工作表与非 ASCII 文本的 XLSX，及含空行的 CSV，均可产出合法 `CompiledDocument`；每个节点的 `sheet/range` 与不可变 version 一致。
- 范围节点行列不重叠、不漏失非空单元格；节点内容和公式不包含工作簿外内容或宏执行结果。
- 无登录、跨空间、非 sheet locator 或不存在范围被拒绝；同空间 viewer 只能读取所请求范围。
- Worker、契约、来源 API/UI 的回归和根质量门禁通过；真实登录态的 XLSX/CSV 上传与预览点击流另行记录。

## 6. 明确后置
