# M7-10-L CSV 解析资源边界 Spec v1

## 1. 关联

- 工作包：`M7-10` 安全复扫；关联 `M2-09` 基础解析、`M4-03` 表格精确回源与 `M7-10-J` XLSX 解析资源边界。
- 发现来源：M7-10 解析资源审阅。CSV 解析先 `read_text()` 全文件，再构造所有行的二维数组；文件准入大小限制不能避免单个 Worker 的不必要内存峰值。
- 影响面：Python `csv_nodes` 与表格 Parser 回归；不改变 CSV 的分隔符识别、范围定位或公式语义。

## 2. 目标

- CSV 不得读取完整文件或构造整表二维数组。
- 以固定行、列和总单元格预算限制 CSV 解析，超限不发布部分节点。

## 3. 规则

- 只读取前 8 KiB 用于 dialect 探测，然后从文件开头用 `csv.reader` 流式读取。
- 最多 50,000 行、256 列和 1,000,000 个声明单元格；超过任一项稳定退出 `CSV_DIMENSION_LIMIT`。
- 保持既有单元格文本截断、200 行/200 KiB 范围节点、空行切块、delimiter metadata 和 SourceLocator 范围。

## 4. 验收标准

- 既有 quoted CSV 解析/范围定位回归保持通过。
- 50,001 行的 CSV 在节点输出前以 `CSV_DIMENSION_LIMIT` 退出。
- 实现不再调用 CSV 的 `Path.read_text()` 或构造整表 `rows = [[...]]`。
- 相关 parser 测试与全量质量门禁通过。

## 5. 非范围

- HTTP 上传体流式 multipart、任意巨大单字段的协议级拒绝、CSV 公式求值、字符集自动识别、独立解析容器或临时磁盘配额。
