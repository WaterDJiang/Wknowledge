# 视频流清单 M4-06 Spec v1

## 1. 关联计划

- 工作包：`M4-06 视频`，前置 M4-07 本地受控媒体探测。
- 当前状态：开发中。首切片读取本地视频容器的音轨与内嵌字幕流清单；MP4 受管上传和文本型内嵌字幕 cue 已由相邻 Spec 接续，关键帧、OCR、视觉描述和视频理解仍未开放。

## 2. 目标与范围

- Python CLI 经受运维控制的 `ffprobe` 列出视频的音频流和 subtitle 流索引、编码、语言/标题标签与默认标记。
- 产物为可验证 `ParserOutput` 的视频元数据补充；不把流名称、字幕文本或封面文字解释为 Agent 指令。
- Worker 只对已存在的受管 `local://` 视频 Blob 运行该 CLI；文件路径、可执行程序与参数不可由用户请求指定。

## 3. 不包含

- 音轨 ASR、关键帧、OCR、视觉描述、video_understanding Provider 或任何云端视频传输。
- 从封装流清单生成 Wiki 知识结论或声称视频已经被理解。

## 4. 安全与验收

- CLI 使用参数数组、30 秒超时、无 Shell；错误为稳定内部代码且不回传 ffprobe stderr 或本地路径。
- 输出仅包含可控的元数据字段；语言/标题字符串长度受限，避免把不可信容器标签无限写入派生产物。
- 对合成 MP4（视频+音轨）输出音轨清单；对无视频流/无正时长/不匹配 MIME 返回既有稳定探测错误。
- MP4 上传、字幕正文的具体边界见相邻 M4-06 Spec；任何网络模型调用保持为零。

## 5. 后续

- 已由 M4-06 音轨转写切片复用：第一条已探测音轨在受控临时目录转为 WAV，由策略相容的 ASR Provider 转写并明确“说了什么”。
- M4-06 后续：关键帧、OCR 和视觉 Provider 各自建立来源、数据策略、运行审计与准确率验收。
