# M7-08 审计导出与保留边界 Spec v1

## 1. 关联计划

- 工作包：`M7-08 审计导出`，复用 `M1-06` 组织审计、`M3-11/M5-01` 查询运行记录与 `M7-02` 配置安全。
- 当前切片：组织管理员可导出受限时间范围的 `audit_event` 元数据；明确默认不自动删除审计记录。

## 2. 目标

- 为管理员提供可下载、可审阅、组织隔离的审计事件 JSON，而非数据库直连或原始表导出。
- 导出仅包含事件 ID、时间、行为、目标类型、目标 ID 与操作者稳定 ID；不输出 event metadata、资料正文、文件名、来源 URI、问题/回答、模型输入输出、密钥、IP、连接串或主机路径。
- 通过固定查询上限和最大时间范围防止导出成为绕过授权、枚举或高成本查询入口。

## 3. 接口与保留规则

```text
GET /api/settings/audit-export?from=<ISO>&to=<ISO>&limit=<1..1000>
```

- 仅 `owner/admin`；未登录 401，其他角色 403。接口不接受 organization ID、用户 ID、目标 ID 或 action 作为客户端筛选条件。
- `from`/`to` 必须为 ISO 时间，`from < to`，范围不超过 31 天；缺失时使用最近 24 小时。单次最多 1,000 条，按时间倒序。
- 响应为 `application/json` 附件；文件名只含 UTC 日期，不含组织名、用户、资料或路径。
- 导出请求本身写入组织审计事件，metadata 只保存条数与时间范围，不保存下载结果。
- 当前保留策略是“不自动清理”。`WKNOWLEDGE_AUDIT_RETENTION_DAYS` 仅作为后续清理任务的只读计划值展示，缺失或非法时为 `null`；本切片不执行删除。

## 4. 验收

- 导出严格按当前管理员组织筛选，跨组织事件绝不出现。
- 导出 Schema 拒绝任何 metadata 和敏感/正文类字段；下载体不包含测试中的秘密或来源 URI。
- 时间范围、limit、权限与导出审计均有回归。
- 设置页提供下载入口及当前“不自动清理/计划保留天数”状态，不要求用户理解底层表。

## 5. 非范围

- 自动清理、法律保留、冻结、签名归档、CSV/PDF、S3 导出、异步超大导出、跨组织汇总或自定义任意条件检索。
