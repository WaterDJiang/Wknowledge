# 学习工作台独立路由 M6-10 Spec v1

## 1. 关联计划

- 工作包：`M6-10`，复用 M6-01 至 M6-09、M6-12、M6-13 已有的计划、课程、练习、测评和报告契约。
- 状态：已验证。本切片只调整学习工作台的信息架构与路由，不修改学习计划、课程、Attempt、Grade、Report 或来源证据的领域真相。

## 2. 目标

- 将学习首页从“所有功能堆叠”调整为概览和继续学习入口。
- 让选材/计划、课程原文、练习、报告分别具有可直达、可刷新的独立 URL。
- 保持现有 API、权限重核、冻结版本和 SourceLocator 行为不变。

## 3. 路由与范围

```text
/workspace/learning             学习概览、下一步入口
/workspace/learning/content     画像、选择已处理资料、计划草稿与确认
/workspace/learning/course      固定版本课程、原文入口和学习事件
/workspace/learning/practice    针对性练习、作答、错题回顾与正式测评入口
/workspace/learning/reports     当前进展、历史快照和 PNG/PDF 导出
/workspace/learning/assessments 已有独立正式测评页
```

- 各路由仅显示本功能域的主操作；概览页不再内嵌内容选择、课程、作答或报告详情。
- 原文仍通过受权的 `/workspace/source` 打开，URL 只携带既有 `wk://source` 和学习单元 ID，不暴露 Blob URI、服务器路径或用户本机路径。
- 练习创建、作答、正式测评冻结、报告快照和下载继续调用既有 API；路由拆分不引入 Skill、模型、Embedding 或后台任务到 Next.js 请求进程。

## 4. 验收标准

- 从概览可进入内容、课程、练习、报告和正式测评；浏览器刷新任一路由不会落回单页锚点或丢失既有数据读取。
- 内容页仍能创建/确认计划；课程页仍能打开固定版本原文并记录事件；练习页仍能作答并跳转正式测评；报告页仍能查看快照和下载已完成 Artifact。
- 未登录、越权、无 active plan、无课程或无完成单元时继续使用已有安全错误/空状态，不显示其他用户的学习数据。
- 已通过全仓类型、单元/集成、构建和 E2E 门禁；浏览器已确认未登录跳转与控制台健康，真实登录后的完整点击流仍待安全可复用会话。

## 5. 明确不在本切片范围

- 单元级 Agent 辅导、模型生成学习计划/题目、掌握度算法、移动端专用导航和新的学习 API。
