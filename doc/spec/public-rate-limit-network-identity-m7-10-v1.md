# M7-10-I 公开限速网络身份边界 Spec v1

## 1. 关联

- 工作包：`M7-10` 安全复扫；关联 `M1-09` 请求安全与持久化限速。
- 发现来源：2026-08-14 安全扫描。公开登录/邀请入口将客户端提供的 `X-Forwarded-For` 或 `X-Real-IP` 直接纳入限速 subject，直接访问 Web 服务的攻击者可每次更换头值绕过同一账号的失败限制。
- 影响面：`enforcePublicMutation`，登录与邀请接受入口；不影响已认证用户按 userId 的写入限速。

## 2. 目标

- 公开接口的应用内限速 subject 不得由客户端任意请求头控制。
- 维持同一公开业务对象（标准化邮箱或邀请 token）的稳定失败计数；不同对象仍隔离。

## 3. 规则

- v1 应用内公开限速忽略 `X-Forwarded-For`、`X-Real-IP` 和所有未经认证的网络身份头，以固定服务端网络身份与既有 `subjectSuffix` 组合。
- 反向代理若需要按源 IP 限流，必须在其边界剥离/重写转发头并独立实施；Next Request 不将这些头视为可信身份来源。
- 已认证 mutation 继续按 `userId` 限速；CSRF 同源校验和错误码不变。

## 4. 验收标准

- 相同 `subjectSuffix` 在不同伪造转发头下产生相同公开限速 subject。
- 不同 `subjectSuffix` 仍产生不同 subject。
- 请求安全相关回归和全量质量门禁通过。

## 5. 非范围

- 反向代理真实客户端 IP 适配、账户锁定、验证码、分布式 WAF 配置、限速窗口/阈值变更或数据库限速存储重构。
