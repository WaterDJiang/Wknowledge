# M7-10-J XLSX 解析资源边界 Spec v1

## 1. 关联

- 工作包：`M7-10` 安全复扫；关联 `M2-09` 基础解析与 `M4-03` 表格精确回源。
- 发现来源：2026-08-14 安全扫描。Worker 已允许合规 XLSX 进入 Python；解析器以 read-only 打开工作簿，但仍将每张表全部值与公式构造成嵌套列表，单个文件可长时间占用 Worker 或造成内存压力。
- 影响面：Python `xlsx_nodes`、表格分块与 XLSX parser 端到端回归。

## 2. 目标

- XLSX 解析不得在内存中保留整张工作表的值/公式二维数组。
- 在遍历单元格前拒绝异常工作表数量、行数、列数、单表单元格数及总单元格数。

## 3. 规则

- `openpyxl` 保持 `read_only=True`；值和公式行按相同顺序流式配对，沿用既有范围节点、来源、公式摘要与截断规则。
- 对每张表的声明维度先执行固定上限检查；任一上限触发时使用稳定 `XLSX_DIMENSION_LIMIT` 失败，不产生部分 ParserOutput。
- 解析结束必须关闭两个工作簿；不增加 Python HTTP/数据库访问，不放宽上传 ZIP 准入。

## 4. 验收标准

- 既有 XLSX 范围、缓存值、公式和分块回归保持通过。
- 使用稀疏但声明超限行数的工作表时，Parser 在节点输出前以 `XLSX_DIMENSION_LIMIT` 退出。
- 实现不再出现 `values = [[...]]` 或 `formulas = [[...]]` 的整表物化。
- 相关 parser 测试和全量质量门禁通过。

## 5. 非范围

- CSV 流式化、PDF/Office 独立容器/cgroup、解析器 CPU/PID/临时磁盘隔离、工作表高级样式/图表语义或增大上传上限。
