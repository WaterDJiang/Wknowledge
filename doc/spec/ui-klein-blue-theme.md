# UI 克莱因蓝主题调整

## 目标

将 Wknowledge 的品牌主色从森林绿调整为克莱因蓝，同时保留米白纸张、中文衬线标题和等宽元数据构成的知识编辑部风格。

## 范围

- 首页、登录页、工作台的主按钮、栏头、侧边栏、焦点状态和装饰阴影。
- 明暗主题中的品牌色。
- 成功、警告、失败等语义状态色不随品牌主色替换。

## 视觉契约

- 主色：International Klein Blue `#002FA7`。
- 深色承载面：`#001B67`。
- 交互悬停：`#174ACB`。
- 淡蓝选中面：`#E7EDFF`。
- 高亮辅色：信号黄 `#FFD447`，只用于按钮偏移阴影和极少量强调。
- 正文与纸张继续使用蓝黑色和暖米白，避免变成普通蓝白后台模板。

## 验收标准

- 三个页面不再出现森林绿品牌承载面。
- 克莱因蓝是面积与视觉权重最大的品牌色。
- 文字与背景对比度保持可读，按钮具备可见 hover/focus 状态。
- 绿色仅保留给“成功、在线、已完成”等语义状态。
- `pnpm format:check && pnpm lint && pnpm typecheck && pnpm test && pnpm build` 通过。
- 浏览器截图检查首页、登录页和工作台。
