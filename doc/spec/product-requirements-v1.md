# Wknowledge 产品需求 v1

## 产品定位

Wknowledge 是单组织私有化部署的多模态知识与学习平台。它把源文件编译成可追溯的 Markdown Wiki，通过 Agent 和 Skill 完成知识加工、问答、学习规划与测评。

## 目标用户

- 需要私有化保存学习资料的个人、团队和部门。
- 需要将 PDF、Word、表格、图片、音频和视频转换为可查询知识的用户。
- 需要基于自有资料安排学习、练习和测评的学习者。

## 核心能力

### 知识资源

- 上传 TXT、Markdown、PDF、DOCX、PPTX、XLSX/CSV、图片、音频和视频。
- 每次替换创建新的不可变 `resource_version`，历史引用不漂移。
- 原始文件不写入 PostgreSQL，数据库只保存元数据、权限、状态和位置。
- 解析生成 `compiled/content.md`、`nodes.json` 及媒体派生物。

### Markdown LLM Wiki

- 知识空间使用 `raw/ → compiled/ → wiki/ → mappings/` 结构。
- Wiki 正文是带 YAML Frontmatter 的 Markdown，含稳定 ID、类型、标签、别名、关联和来源。
- 查询先读 `index.md`，再根据分域索引、别名和文本搜索读取具体页面。
- 无证据时明确拒答；不得把模型常识冒充成知识库内容。
- 首期不使用向量数据库，不在查询链路调用 Embedding。

### 精确回源

- PDF 引用定位到页码与可选区域。
- 音视频引用定位到时间段。
- 表格引用定位到工作表和单元格范围。
- PPT 引用定位到幻灯片和 Shape，Word 定位到结构节点。
- 浏览器版只承诺平台受管 URI，不伪造用户电脑绝对路径。

### Agent、Skill 与模型

- 知识问答采用可恢复的多轮 Agent 会话，不再只是单次查询表单。
- 会话可挂载一个或多个已授权知识库为受管只读虚拟路径；路径只是权限绑定，不是宿主机绝对路径。
- Agent 按需发现 Skill，使用 `allow/ask/deny` 级别权限。
- 用户可查看 Skill 调用、知识检索、模型生成、停止和失败状态。
- Skill 版本化，定义 JSON Schema、资源权限、网络允许列表和资源限额。
- 长任务只在 Worker 中执行；Next.js 请求进程只创建任务和返回进度。
- 模型网关按数据出域策略、能力、允许列表、质量、成本和 fallback 路由。
- 能力包括 chat、vision、embedding、rerank、STT、TTS、图片和视频。

### 学习应用

- 学习画像区分用户声明、系统观察和 AI 推断。
- 用户先选择知识库内容和学习目标，再由 Skill 生成计划候选，用户确认后生效。
- 课程包含模块、学习单元和知识点。
- 文字、PDF、图片和音视频通过统一原文阅读器进入学习单元，记录页码、时间点和完成事件。
- 练习 Skill 可以按已学范围、难度和历史结果生成针对性题目。
- 正式练习和测评题必须关联知识点和来源定位。
- 作答、评分、反馈、题目版本和耗时写入数据库，后续生成结构化报告和报告图片。
- 历史计划、作答、评分和知识版本不被后续更新覆盖。

## 角色与权限

| 角色    | 主要权限                       |
| ------- | ------------------------------ |
| owner   | 组织、用户、模型和全部知识空间 |
| admin   | 用户、空间、审计和任务管理     |
| editor  | 上传、编译、纠错和课程编排     |
| learner | 阅读、问答、学习、练习和测评   |
| viewer  | 只读已授权的 Wiki 与来源       |

## MVP 边界

MVP 必须完成：登录、权限、知识空间、文件上传、后台处理、Markdown Wiki 编译、查询、来源定位、Skill 和模型基础契约。

MVP 不包含：向量数据库、FastAPI、知识图谱数据库、多租户 SaaS、桌面同步、移动 App、多 Agent 自主协作和自动公开发布。

## 验收标准

- 未登录请求返回 401，无空间权限返回 403。
- 原文不写入数据库，原始文件不被 Skill 修改。
- 重复编译不产生重复 Wiki 页面或来源。
- 同一知识空间的发布任务串行化，Lint 失败不覆盖已发布 Wiki。
- 无证据问题拒答，所有引用可解析为 `SourceLocator`。
- 查询链路不依赖向量库且不调用 Embedding。
- 题目、评分与学习状态可追溯到知识版本和原文定位。
