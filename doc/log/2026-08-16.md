# 2026-08-16 实施记录

## M7-01/M7-02/M7-11：限制性 umask 导致镜像内非 root 读取失败

- GitHub Actions 运行 `31821756177` 已执行到 preflight，原始错误为 `Error: EACCES: permission denied, open '/app/deploy/preflight.mjs'`，触发命令为 Compose `preflight` 服务的 `node deploy/preflight.mjs`。因此工作流外层健康检查被跳过。
- 根因不是 Git 可执行位：`deploy/preflight.mjs` 记录为普通 `100644`，Node 只需读取。远程脚本先以 `umask 077` 创建受限运行时凭据，再在未恢复 umask 的情况下 Git 检出；Docker `COPY` 保留了 root-only 模式，镜像切换至 uid `10001` 的 `wknowledge` 后无法读取源码。
- 部署脚本在运行时环境文件已经 `chmod 600` 后恢复 `umask 022`，Dockerfile 在切换运行用户前将整个 `/app` 归属给 `wknowledge`。这同时修复已存在检出文件的模式，并不放宽服务器凭据文件权限。
