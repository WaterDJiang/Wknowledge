## M2-04 事务 Outbox 与可靠投递

- 数据：新增 `job_outbox` 及 `0009_fresh_outbox.sql`；每个 ProcessingJob 唯一一条投递意图，只保留状态、尝试数、短租约、队列 ID 与脱敏错误码，不保存文件正文、Blob URI 或堆栈。

- 一致性：多 drain 使用数据库短租约，只有领取 token 的实例可确认 sent 与写 queueJobId。broker 确认前发生不确定投递时保持至少一次投递，后续执行以既有 ProcessingJob execution token 领取保证并发不重复执行业务任务。
- 验证：迁移已应用。上传首次 broker 失败保持 resource/job queued + pending outbox、下次补偿成功、并发 drain 单次 publish、过期 dispatching 接管、取消拒发、resume fallback 均有 PostgreSQL 集成覆盖。
