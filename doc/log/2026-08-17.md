- 回归测试先原样失败：`expected deploy.sh to contain chmod 644 "$app_dir/deploy/nginx/wknowledge.conf"`。部署脚本现于每次 checkout/clean 后仅把公开 Nginx 配置恢复为 `0644`，不改变 `runtime.env` 的 `0600`。

## M1-09：HTTPS 反向代理同源校验修复

- 线上只读复现：`POST https://knowledge.wattter.cn/api/auth/login` 携带 `Origin: https://knowledge.wattter.cn` 返回 `403 CSRF_ORIGIN_DENIED`。
- 根因：宝塔 HTTPS 配置正确传入 `Host` 和 `X-Forwarded-Proto: https`，但应用只使用容器内部请求 URL 的 `http` 协议构造期望 Origin，导致 HTTPS 浏览器写请求被误判为跨站。
- 修复：同源校验优先采用明确的 `http`/`https` 转发协议，并继续以当前 Host 匹配 Origin；新增单元回归覆盖 HTTPS 反代通过与真实跨站拒绝。
- 验证：目标 Vitest 4 passed；根 `pnpm test` 为 62 files passed、25 skipped，252 tests passed、103 skipped；`pnpm format:check`、`pnpm lint`、`pnpm typecheck`、`pnpm build` 与认证 Playwright 2 passed 均通过。
