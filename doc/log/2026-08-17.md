## M7-01/M7-02/M7-11：修复历史检出残留的 Nginx 配置权限

- 服务器 firewalld 的 Docker bridge 未加入 `docker` zone，导致容器访问 PostgreSQL 与 DNS 均报 `EHOSTUNREACH`；已将 `br-b641ce596b1d` 即时并永久加入 `docker` zone，临时容器验证返回 `postgres:5432 - accepting connections`。
- GitHub Actions 重跑 `31957867814` 后，`migrate` 成功，PostgreSQL、Web 和 Worker 均健康；gateway 日志原样报错 `open() "/etc/nginx/nginx.conf" failed (13: Permission denied)`。
- 服务器只读检查确认 SELinux 为 `Disabled`，挂载源 `/opt/wknowledge/app/deploy/nginx/wknowledge.conf` 为 `0600`，而 Git 只记录普通文件 `100644`。旧检出受 `umask 077` 影响，后续 `checkout --force` 不会恢复组/其他用户读位。
- 回归测试先原样失败：`expected deploy.sh to contain chmod 644 "$app_dir/deploy/nginx/wknowledge.conf"`。部署脚本现于每次 checkout/clean 后仅把公开 Nginx 配置恢复为 `0644`，不改变 `runtime.env` 的 `0600`。
