# 2026-08-12

## 初始化 Wknowledge

- 目标：建立私有化多模态知识与学习平台的 Spec、Harness 和纵向 MVP。
- 决策：Next.js + Node Worker + PostgreSQL；Python 只作为工具运行时，不提供 FastAPI。
- 决策：Markdown Wiki 是知识正文，PostgreSQL 是权限和状态真相。
- 决策：MVP 查询只使用分层索引、别名和文本搜索，不使用向量库。
- 实现：建立 12 个 pnpm workspace 项目，覆盖 Web、Worker、契约、数据库、认证、Blob、Wiki、Skill、Agent 和模型路由。
- 实现：PostgreSQL 15 张业务表、Drizzle SQL migration、单组织种子账号、HttpOnly 会话和空间 RBAC。
- 实现：上传哈希去重、不可变 Blob、资源版本、pg-boss 任务、SSE 进度、标准 `content.md`/`nodes.json`。
- 实现：TXT/MD/CSV 由 Node 解析；PDF/DOCX/PPTX/XLSX 通过无 HTTP、无数据库权限的 Python JSON CLI 解析。
- 实现：Wiki staging、Frontmatter/来源 Lint、原子发布、根索引查询、拒答、`wk://` SourceLocator 回源。
- 实现：4 个内置 Wiki Skill 及摘要校验、Skill 权限门禁、模型能力路由和 Wiki Embedding 硬禁止。
- 实现：内容优先的响应式 UI，包括首页、登录、空间、上传、状态和问答。
