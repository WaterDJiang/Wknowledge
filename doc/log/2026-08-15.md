## M7-01/M7-02/M7-11：SSH 标准输入被 Compose Run 消费

- GitHub Actions 运行 `31814709840` 完成固定 SHA 镜像构建后，仅创建了 `wknowledge` 网络和卷；日志未出现 preflight、`docker compose up` 或 `DEPLOY_SUCCEEDED`，随后独立远程健康检查对 `127.0.0.1:13000` 返回 `curl: (7) Connection refused`。
- 根因是远程部署脚本本身通过 SSH 标准输入传入，而两个一次性 `docker compose run` 默认保持并附着标准输入；第一个容器读取了脚本剩余内容，父 Bash 因 EOF 以成功状态退出。`127.0.0.1` 位于 SSH 的远程服务器上下文，地址本身正确。
- 两个一次性 Compose 调用现均以 `</dev/null` 运行，保持后续 preflight、Compose 启动、内层健康检查和成功标记可执行；新增静态回归防止该重现路径回归。
