## 本轮计划变更

- `M5-01` 至 `M5-12` 的知识问答正式收敛为“显式知识 Binding + 受管虚拟路径 + `knowledge.search/read` + 按 Policy 调用 Skill + 自然语言回答/独立来源区”的对话工作台；不再以单轮检索页作为完成定义。
- `M6-03/M6-06/M6-07/M6-08/M6-11/M6-13` 的生成型能力正式收敛为“选材 → candidate/draft → 用户/领域服务确认 → 固定原文/作答/评分 → 确定性报告”的闭环；当前确定性学习功能保持可用，生成型计划/题目 Skill 已具备受管 Worker 切片但仍需管理员配置兼容 Provider 才会启用，量表 Skill 尚未接入。
- 开源采用保持 Adapter 优先：Pi 仅为 Agent Core 候选，OpenCode 仅为 Skill/权限语义参考，Claude Code 仅为公开 UX/Hook 安全对照；三者均未作为生产运行时安装。
- `M7-04` 按“先双读 v1 与历史无清单状态，再维护窗口清单化迁移，最后才允许未来 v2 写入”推进；当前不制造没有业务语义的 Frontmatter v2。
